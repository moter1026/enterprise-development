# Car Rental Point System

Система управления пунктом проката автомобилей, построенная на .NET 8 с архитектурой **Domain – Application – Infrastructure – API** и покрытая модульными тестами на xUnit.

---

## Архитектура решения

### **1. CarRentalPoint.Domain**
Содержит доменную модель и бизнес-логику:

- **Entities** — основные сущности (`Car`, `CarModel`, `ModelGeneration`, `Client`)
- **Enums** — перечисления, используемые в домене
- **Interfaces** — доменные интерфейсы
- **Contract** — контракт доменных сервисов (`Rental`)
- **InitialData** — стартовые данные для сидирования (`CarRentalDataSeeder`)

---

### **2. CarRentalPoint.Application**
Слой прикладной логики:

- **DTOs** — модели для передачи данных
- **Mappers** — отображения сущностей в DTO и обратно

---

### **3. CarRentalPoint.Infrastructure**
Реализация доступа к данным:

- **Persistence** — контекст, конфигурации и настройки хранения (`AppDbContext` и `DbSeeder`)
- **Repositories** — реализации репозиториев (generic `EfRepository`)
- **Migrations** — миграции базы данных

---

### **4. CarRentalPoint.Api**
REST API приложения:

Контроллеры:

- `CarsController`
- `CarModelsController`
- `ModelGenerationsController`
- `ClientsController`
- `RentalsController`
- `AnalyticsController` — контроллер для вывода логики, описанной в юнит-тестах

Также содержит:

- Конфигурацию приложения
- Настройку DI-контейнера

---

### **5. CarRentalPoint.AppHost**
Проект-хост:

- Используется для запуска приложения (`Api`)
- Содержит точку входа и базовые настройки хоста
- Интегрируется с ServiceDefaults

---

### **6. CarRentalPoint.ServiceDefaults**
Общий проект с настройками и конфигурациями:

- Общие настройки сервисов

---

### **7. CarRentalPoint.Tests**
Проект модульных тестов на **xUnit**:

Проверяет:

- Поиск клиентов по арендованной модели
- Определение автомобилей, находящихся в аренде
- Топ-5 наиболее арендуемых автомобилей
- Статистику аренд по автомобилям
- Топ-5 клиентов по сумме аренд

---

### **CarRentalPoint.Api.Grpc**
Модуль gRPC:

- Реализует сервис RentalReceiver с потоковой передачей данных для:
- StreamRentals – поток аренды
- StreamClients – поток клиентов
- StreamCars – поток автомобилей

Поддерживает:

- Batch-обработку для оптимизации сохранения данных
- Ограничение размера сообщений (PayloadLimitBytes)
- Настраиваемые параметры через RentalReceiverOptions

Клиентская часть может отправлять данные в реальном времени с использованием Worker:
- Случайная генерация аренды, клиентов и машин
- Параллельная отправка сообщений в соответствующие потоки
- Асинхронный приём и логирование ответов сервера

---

## Основные функции

- **Управление автомобилями** - учет моделей, поколений и физических характеристик автомобилей
- **Работа с клиентами** - ведение базы клиентов и их данных
- **Оформление аренды** - система бронирования и учета арендных операций
- **Аналитика** - отчеты и статистика по арендам

---

## Сущности системы

- `CarModel` - справочник моделей автомобилей
- `ModelGeneration` - поколения моделей с техническими характеристиками
- `Car` - автомобили в автопарке
- `Client` - клиенты сервиса
- `Rental` - договоры аренды
