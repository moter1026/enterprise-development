# Car Rental Point System

Система управления пунктом проката автомобилей на C# с использованием .NET и xUnit для тестирования.

## Описание проекта

Система предоставляет функционал для управления автопарком, клиентами и арендой автомобилей. Включает в себя основные бизнес-сущности и операции для работы сервиса каршеринга.

## Основные функции

- **Управление автомобилями** - учет моделей, поколений и физических характеристик автомобилей
- **Работа с клиентами** - ведение базы клиентов и их данных
- **Оформление аренды** - система бронирования и учета арендных операций
- **Аналитика** - отчеты и статистика по арендам

## Сущности системы

- `CarModel` - справочник моделей автомобилей
- `ModelGeneration` - поколения моделей с техническими характеристиками
- `Car` - автомобили в автопарке
- `Client` - клиенты сервиса
- `Rental` - договоры аренды

## Тестирование

Проект включает комплекс unit-тестов, проверяющих:

- Поиск клиентов по арендованной модели
- Определение автомобилей в текущей аренде
- Топ-5 наиболее арендуемых автомобилей
- Статистика аренд по автомобилям
- Топ-5 клиентов по сумме аренд

## Технологии

- .NET 8.0
- xUnit для тестирования
- C# 12.0
